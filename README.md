# DeepSeek для Galaxy Watch 5

Неофициальный клиент DeepSeek для часов на Wear OS (Galaxy Watch 4/5/6/7 и другие с Wear OS 3+).
Приложение работает на часах самостоятельно и обращается к официальному API DeepSeek
через Wi‑Fi часов или через телефон по Bluetooth.

## Возможности

- Вопрос голосом (🎤) или с клавиатуры часов (⌨). На Galaxy Watch в окне ввода также есть рукописный ввод и «Ввод на телефоне».
- Ответ появляется по мере генерации, как в чате на телефоне.
- Прокрутка выполняется безелем (на Watch 5 — круговым движением пальца по краю экрана) или свайпом.
- Кнопка «■ Стоп» прерывает ответ.
- Кнопка «🔊 Озвучить» читает ответ голосом через динамик часов.
- Контекст диалога сохраняется: можно задавать уточняющие вопросы. История переживает перезапуск приложения.
- Пока идёт ответ, экран не гаснет.
- Настройки:
  - ключ API;
  - модель (`deepseek-flash` — быстрая и дешёвая, `deepseek-v4-pro` — мощнее, можно указать любую другую);
  - режим «Размышление»;
  - размер шрифта (13–19 sp);
  - системная подсказка (по умолчанию: «отвечай кратко, по-русски, без разметки»).
- Свайп вправо возвращает на предыдущий экран.

## 1. Ключ API DeepSeek

1. Зарегистрируйтесь на <https://platform.deepseek.com>.
2. Пополните баланс (раздел *Top up*). API оплачивается отдельно от бесплатного чата на сайте, по числу токенов. Короткие вопросы с часов стоят доли копейки.
3. Откройте *API keys* → *Create new API key* и скопируйте ключ вида `sk-…`. Он показывается только один раз.

Передать ключ на часы можно тремя способами (подробнее в разделе 4):

- **при сборке** — вписать в `local.properties`, и ключ будет вшит в APK (самый простой способ);
- **командой adb** с компьютера;
- **вручную на часах**: Настройки → Ключ API.

## 2. Сборка в Android Studio (рекомендуется)

### Установка Android Studio

Fedora 44 или Linux Mint, через Flatpak:

```bash
flatpak install flathub com.google.AndroidStudio
flatpak run com.google.AndroidStudio
```

При первом запуске мастер сам скачает Android SDK. Выбирайте вариант *Standard*.

### Сборка

1. Распакуйте архив проекта, например в `~/Projects/DeepSeekWatch`.
2. Android Studio → **Open** → выберите папку `DeepSeekWatch`.
   Дождитесь окончания синхронизации Gradle (полоса внизу). В первый раз она занимает 3–10 минут.
3. Скопируйте `local.properties.example` в `local.properties` (если Studio уже создала этот файл, просто добавьте в него строку) и впишите:
   ```
   deepseek.apiKey=sk-ваш_ключ
   ```
4. Выберите в меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл появится здесь:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```

> Если Studio предложит обновить Android Gradle Plugin («AGP Upgrade Assistant»), можно согласиться или отказаться. Проект собирается и так.

## 3. Сборка из командной строки (без Android Studio)

```bash
# JDK 21
sudo dnf install java-21-openjdk-devel        # Fedora
sudo apt install openjdk-21-jdk               # Linux Mint

# Android SDK command-line tools:
# скачайте commandlinetools-linux-*_latest.zip со страницы
# https://developer.android.com/studio#command-tools
mkdir -p ~/Android/Sdk/cmdline-tools
unzip commandlinetools-linux-*_latest.zip -d ~/Android/Sdk/cmdline-tools
mv ~/Android/Sdk/cmdline-tools/cmdline-tools ~/Android/Sdk/cmdline-tools/latest

export ANDROID_HOME=~/Android/Sdk
export PATH=$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$PATH

sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

# Сборка
cd ~/Projects/DeepSeekWatch
cp local.properties.example local.properties   # впишите sdk.dir и deepseek.apiKey
chmod +x gradlew
./gradlew assembleDebug
```

## 3а. Сборка на GitHub без установки чего-либо

В проекте уже есть сценарий `.github/workflows/build-apk.yml`. GitHub соберёт APK на своём сервере бесплатно.

1. Зарегистрируйтесь на github.com и создайте репозиторий: **New repository**, лучше выбрать **Private**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите в окно **содержимое** папки `DeepSeekWatch`, включая скрытую папку `.github`. Нажмите **Commit changes**.
   > Скрытые папки в Linux показываются по Ctrl+H. Если `.github` не загрузилась, создайте файл
   > вручную: **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, и вставьте его текст.
3. Откройте вкладку **Actions**. Сборка запустится сама и займёт 5–8 минут. Если не запустилась, нажмите **Build APK → Run workflow**.
4. Когда появится зелёная галочка, откройте запуск и скачайте внизу, в разделе **Artifacts**, архив `DeepSeekWatch-apk.zip`. В нём лежит `app-debug.apk`.
5. Если появился красный крестик, откройте шаг «Сборка» и скопируйте текст ошибки.

Ключ API в этом случае удобнее передать командой из п. 4.4. Можно и вшить его через секрет `DEEPSEEK_API_KEY`
(Settings → Secrets and variables → Actions), но только в приватном репозитории.

## 4. Установка на Galaxy Watch 5

### 4.1. Утилита adb на компьютере

```bash
sudo dnf install android-tools    # Fedora
sudo apt install adb              # Linux Mint
```

Если ставили SDK из раздела 3, `adb` уже есть в `~/Android/Sdk/platform-tools`.

### 4.2. Режим разработчика на часах

1. **Настройки → Сведения о часах → Сведения о ПО**. Нажмите на **Версия ПО** 5–7 раз, пока не появится сообщение «Режим разработчика включён».
2. **Настройки → Параметры разработчика**:
   - включите **Отладка ADB**;
   - включите **Отладка по Wi‑Fi**.
3. Подключите часы к той же сети Wi‑Fi, что и компьютер (Настройки → Подключения → Wi‑Fi).

> Совет: часы любят переключаться обратно на Bluetooth и отключать Wi‑Fi. На время установки
> выключите Bluetooth на часах или в настройках Wi‑Fi выберите «Всегда включено».

### 4.3. Сопряжение и установка

На часах откройте **Отладка по Wi‑Fi → Подключить новое устройство**. Появятся адрес вида
`192.168.1.50:37123` и шестизначный код.

```bash
adb pair 192.168.1.50:37123        # введите код с экрана часов
```

Вернитесь на экран **Отладка по Wi‑Fi**. Там указан **другой** порт для подключения, например `192.168.1.50:41567`.

```bash
adb connect 192.168.1.50:41567
adb devices                        # часы должны быть в списке со статусом device
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Сопряжение (`adb pair`) нужно только один раз. В следующие разы достаточно `adb connect`.
На часах может появиться запрос «Разрешить отладку?» — нажмите «Разрешить».

### 4.4. Ключ без пересборки (если не вшивали его в APK)

```bash
adb shell am start -n io.github.dswatch/.MainActivity --es api_key sk-ваш_ключ
```

На часах появится сообщение «Ключ API сохранён».

### 4.5. Удаление

```bash
adb uninstall io.github.dswatch
```

Или на часах: долгое нажатие на иконку → Удалить.

## 5. Работа с приложением

| Действие | Как |
|---|---|
| Спросить | «🎤 Спросить голосом» или «⌨ Ввести текст» |
| Прокрутить ответ | безель / свайп вверх‑вниз |
| Прервать ответ | «■ Стоп» |
| Прослушать ответ | «🔊 Озвучить» под ответом |
| Уточнить | ещё один вопрос — контекст сохраняется |
| Начать заново | «✚ Новый чат» |
| Настройки | «⚙ Настройки», назад — свайп вправо |

Режим **«Размышление»** по умолчанию выключен: на часах важнее скорость. Включайте его для
задач, где нужна точность (расчёт, логика). Пока модель думает, на экране виден счётчик «Размышляю… N».

## 6. Неполадки

| Сообщение / симптом | Что делать |
|---|---|
| «Неверный ключ API» | Проверьте ключ (Настройки → Ключ API) или задайте его заново командой из п. 4.4 |
| «На балансе DeepSeek закончились средства» | Пополните баланс на platform.deepseek.com |
| «Некорректный запрос (проверьте имя модели)» | DeepSeek могла переименовать модели. Сверьте названия на api-docs.deepseek.com и введите нужное через «Своя модель…» |
| «Нет подключения к интернету» | Часы должны быть на Wi‑Fi или в связи с телефоном (приложение Galaxy Wearable) |
| Голосовой ввод не открывается | Автоматически откроется клавиатура — в ней тоже есть микрофон |
| «Для синтеза речи не установлен русский голос» | Настройки часов → Общие → Преобразование текста в речь → выберите движок и язык «Русский» |
| `adb: failed to connect` | Часы уснули или сменили порт. Разбудите их, откройте «Отладка по Wi‑Fi» и повторите `adb connect` с новым портом |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | Удалите старую версию (`adb uninstall io.github.dswatch`) и установите снова |

## 7. Устройство проекта

```
DeepSeekWatch/
├── app/build.gradle.kts            зависимости, вшивание ключа из local.properties
└── app/src/main/
    ├── AndroidManifest.xml         приложение для часов, standalone
    └── java/io/github/dswatch/
        ├── MainActivity.kt         запуск, тема, навигация, приём ключа через adb
        ├── ChatViewModel.kt        логика диалога, «Стоп», озвучивание
        ├── DeepSeekClient.kt       запрос к API и разбор потока SSE
        ├── SettingsStore.kt        настройки и история (SharedPreferences)
        ├── TextUtil.kt             очистка Markdown, разбивка на абзацы
        └── ui/
            ├── ChatScreen.kt       экран диалога
            ├── SettingsScreen.kt   экран настроек
            └── InputLaunchers.kt   голосовой и клавиатурный ввод Wear OS
```

Стек: Kotlin 2.0, Jetpack Compose for Wear OS 1.4, OkHttp 4. minSdk 30 (Wear OS 3), targetSdk 34.

**Безопасность ключа.** Ключ хранится только на ваших часах. Если вы вшили его в APK через
`local.properties`, никому не передавайте этот APK: ключ можно извлечь из файла.
